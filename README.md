# davidrossi

Personal website for David Rossi, served with GitHub Pages.

Plain HTML and CSS, no build step. Edit `index.html` for content and `styles.css` for styling.

## Publishing

In the repo's **Settings → Pages**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`. The `CNAME` file serves the site at https://davidrossi.com.au.

Brand icons in `assets/icons/` are from [Simple Icons](https://simpleicons.org) (CC0). Website thumbnails are static screenshots in `assets/sites/` where available, otherwise generated by the WordPress mShots screenshot service.

After changing `styles.css`, bump the `?v=` number on its `<link>` in `index.html` so browsers fetch the new version instead of a cached one.
